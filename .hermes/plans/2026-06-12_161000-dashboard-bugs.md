# Dashboard — Bugs y Mejoras

**Goal:** Fix visual bugs and improve the Dashboard page layout, components, and UX.

---

## Bugs

### DB1 — `align-center` en PeriodBreakdown.vue (no es clase Tailwind)

**File:** `src/components/ftbot/PeriodBreakdown.vue:84`

```html
<div class="flex align-center justify-between">
```

**Problema:** `align-center` no existe en Tailwind. Debería ser `items-center`.

---

### DB2 — Debug console.log en DashboardView.vue

**File:** `src/views/DashboardView.vue:71-72`

```ts
console.log('newlayout', [...newLayout, ...hiddenItems]);
console.log('saving dashboard');
```

**Problema:** Logs de debug en producción. Además, `console.log` deja el array en memoria.

**Fix:** Comentar o eliminar.

---

### DB3 — Console.log comentado en DashboardView.vue:10

```ts
// console.log('breakpoint:', newBreakpoint);
```

Es código muerto. Eliminar.

---

### DB4 — Código comentado en DashboardView.vue:101

```ts
// botStore.activeBot.getTrades();
```

Eliminar.

---

### DB5 — Badge con `items-center` sin display flex

**File:** `src/components/ftbot/BotComparisonList.vue:113,143,152,157,244,251,258`

```html
<Badge class="items-center ..." ...>
```

**Problema:** `items-center` solo funciona en contenedores flex. PrimeVue `Badge` es `display: inline-flex` por defecto? Depende de la versión. Si no es flex, `items-center` no hace nada. Además, muchos Badges tienen estilos inline como `bg-green-800` que pueden no aplicarse correctamente porque PrimeVue Badge sobrescribe los colores con sus propias variables CSS.

**Fix:** Verificar que los Badges se vean correctamente. Agregar `flex` explícito si es necesario.

## Mejoras

### DI1 — BotComparisonList: Summary row no tiene fondo distintivo

**File:** `src/components/ftbot/BotComparisonList.vue:101` (push summary)

La fila Summary al final de la tabla no tiene diferenciación visual (color de fondo, borde).

**Fix:** Agregar clase `font-bold bg-surface-500/10` a la celda o fila del summary.

### DI2 — PeriodBreakdown: botón refresh poco visible

**File:** `src/components/ftbot/PeriodBreakdown.vue:78`

```html
<Button class="float-end" severity="secondary" @click="refreshSummary">
```

`float-end` no es clase Tailwind (debería ser `float-right` o mejor usar flex). Además, el botón está fuera del flujo del layout.

**Fix:** Cambiar `float-end` por `ms-auto` en un contenedor flex.

### DI3 — Dashboard no muestra estado de carga

**File:** `src/views/DashboardView.vue`

Cuando los datos se están cargando (getDaily, getOpenTrades, getProfit), no hay indicador visual.

**Fix:** Agregar un estado `isLoading` que muestre un `ProgressSpinner` mientras se cargan los datos iniciales.

### DI4 — GridLayout se rompe con `vertical-compact="false"` + `prevent-collision="true"`

**File:** `src/views/DashboardView.vue:112-118`

La combinación de `vertical-compact="false"` (no compactar verticalmente) y `prevent-collision="true"` (prevenir colisiones) puede causar espacios vacíos enormes entre paneles cuando uno se cierra. Los items ocupan su posición original pero los items debajo no se mueven para llenar el espacio.

**Fix:** Revisar si `vertical-compact="false"` es necesario. Si no, cambiarlo a `true` para que los items se compacten automáticamente.
