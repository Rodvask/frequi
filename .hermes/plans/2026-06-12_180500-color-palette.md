# Paletas de Color — Propuestas

**Current:** Amber/gold (#f59e0b) — cálido pero se ve opaco en fondos claros.

---

## Opción A — Azul Profesional (recomendada)

Limpio, moderno, el estándar en dashboards financieros/crypto.

```css
/* Light */
--p-primary-50: #eff6ff;
--p-primary-100: #dbeafe;
--p-primary-200: #bfdbfe;
--p-primary-300: #93c5fd;
--p-primary-400: #60a5fa;
--p-primary-500: #3b82f6;   /* Primary */
--p-primary-600: #2563eb;
--p-primary-700: #1d4ed8;
--p-primary-800: #1e40af;
--p-primary-900: #1e3a8a;
--p-primary-950: #172554;

--ft-accent-light: #2563eb;
--ft-accent-light-hover: #1d4ed8;
--ft-accent-light-active: #1e40af;
--ft-accent-light-rgb: 37 99 235;

/* Dark */
--ft-accent-dark: #60a5fa;
--ft-accent-dark-hover: #93c5fd;
--ft-accent-dark-active: #3b82f6;
--ft-accent-dark-rgb: 96 165 250;
```

**Vibra:** Profesional, confiable, sereno. Similar a: TradingView, Coinbase, Binance.

---

## Opción B — Teal/Verde Azulado

Moderno, fresco, menos agresivo que el azul puro.

```css
--p-primary-500: #14b8a6;   /* teal-500 */
--p-primary-600: #0d9488;
--p-primary-700: #0f766e;

--ft-accent-light: #0d9488;
--ft-accent-light-rgb: 13 148 136;
--ft-accent-dark: #2dd4bf;
--ft-accent-dark-rgb: 45 212 191;
```

**Vibra:** Fresco, moderno, natural. Similar a: Notion, Vercel.

---

## Opción C — Índigo/Violeta

Sofisticado, elegante, diferencia visual.

```css
--p-primary-500: #6366f1;   /* indigo-500 */
--p-primary-600: #4f46e5;
--p-primary-700: #4338ca;

--ft-accent-light: #4f46e5;
--ft-accent-light-rgb: 79 70 229;
--ft-accent-dark: #818cf8;
--ft-accent-dark-rgb: 129 140 248;
```

**Vibra:** Elegante, creativo, premium. Similar a: Linear, Tailwind UI.

## Además del primario, mejoraría:

### Fondos más limpios:
```css
/* Light - más limpio que el actual #f5f7fa */
--ft-bg: #f8f9fc;          /* ligeramente más claro */
--ft-bg-muted: #f1f3f8;
--ft-panel: rgba(255,255,255,0.98);  /* menos transparente */
--ft-panel-strong: #ffffff;
--ft-panel-border: rgba(15, 23, 42, 0.07);  /* borde más sutil */

/* Dark - más profundo */
--ft-bg: #05080f;           /* más rico que #02040b */
--ft-panel: rgba(9, 14, 26, 0.97);
--ft-panel-border: rgba(148, 163, 184, 0.10);  /* más sutil */
```

### Profit/Loss más vibrantes:
```css
--color-profit: #12b981;   /* verde más limpio que #12bb7b */
--color-loss: #ef4444;     /* rojo más limpio que #ef5350 */
```
