# History Page — Bugs y Mejoras (Desktop + Mobile)

**Goal:** Fix bugs and improve the Trade History page (`/trade_history`).

**Files:** `src/views/MobileTradesListView.vue`, `src/styles/tailwind.css`

---

## Bugs

### HB1 — `reduce` en array vacío puede lanzar error

**File:** `src/views/MobileTradesListView.vue:11-17`

```ts
const historyProfit = computed(() =>
  closedTrades.value.reduce(
    (sum, trade) => sum + (trade.profit_abs ?? trade.realized_profit ?? 0),
    0,
  ),
);
```

**Problema:** Tiene valor inicial `0`, por lo que funciona con array vacío. No es bug. Pero `historyProfitFormatted` usa `.toFixed(2)` que no maneja locale correctamente.

**Fix para formateo:** Usar `formatPriceCurrency`:
```ts
const historyProfitFormatted = computed(() =>
  formatPriceCurrency(historyProfit.value, botStore.activeBot.stakeCurrency),
);
```

---

### HB2 — Break-even trades contados como pérdidas

**File:** `src/views/MobileTradesListView.vue:21-23`

```ts
const losingTrades = computed(
  () => closedTrades.value.filter((trade) => (trade.profit_ratio ?? 0) <= 0).length,
);
```

**Problema:** Trades con `profit_ratio === 0` (break-even) se cuentan como pérdidas. Deberían contarse como neutrales o no contar en losses.

**Fix:** Cambiar `<= 0` a `< 0`:
```ts
const losingTrades = computed(
  () => closedTrades.value.filter((trade) => (trade.profit_ratio ?? 0) < 0).length,
);
```

---

### HB3 — Sin indicador de carga

**File:** `src/views/MobileTradesListView.vue`

**Problema:** Cuando los trades se están cargando, no hay feedback visual. El usuario ve métricas en 0 o tabla vacía.

**Fix:** Verificar si hay datos cargando y mostrar spinner:
```html
<ProgressSpinner v-if="!closedTrades.length" class="w-5 h-5" />
```

---

### HB4 — `historyProfitFormatted` no usa las utilidades de formato del proyecto

**File:** `src/views/MobileTradesListView.vue:17`

```ts
const historyProfitFormatted = computed(() => historyProfit.value.toFixed(2));
```

**Problema:** `.toFixed(2)` produce string como `"-12.34"` sin símbolo de moneda ni separadores de miles. El proyecto tiene `formatPriceCurrency` para esto.

**Fix:** Reemplazar con:
```ts
const historyProfitFormatted = computed(() =>
  formatPriceCurrency(historyProfit.value, botStore.activeBot.stakeCurrency),
);
```

## Mejoras Mobile

### HMI1 — Las métricas ocupan 2×2 en mobile, información densa

**File:** `src/styles/tailwind.css:2805-2808`

```css
.ft-history-metrics {
  grid-template-columns: repeat(2, minmax(0, 1fr));
}
```

4 tarjetas en 2 columnas = 2 filas. Se ve bien, pero en pantallas muy pequeñas (< 400px) podría ser mejor 1 columna.

**Fix:** Agregar media query para pantallas < 400px:
```css
@media (max-width: 400px) {
  .ft-history-metrics {
    grid-template-columns: 1fr;
  }
}
```
