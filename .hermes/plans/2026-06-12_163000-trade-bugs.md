### TD2 — forceSellMulti usa `xxx` como nombre de variable

**File:** `src/components/ftbot/TradeList.vue:148`

### TD4 — scroll-height="flex" en DataTable puede romper el layout

**File:** `src/components/ftbot/TradeList.vue:235`

```html
scroll-height="flex"
```

En algunas versiones de PrimeVue, `scroll-height="flex"` dentro de un contenedor con altura dinámica (DraggableContainer) puede causar que el DataTable tenga altura 0 o se desborde.

**Fix:** Verificar que funcione correctamente. Alternativa: usar `scroll-height="calc(100%)"` o quitar scrollable y dejar que el contenedor padre maneje el overflow.

### TD5 — Filtro en TradeList no usa el `filterText` para paginación

**File:** `src/components/ftbot/TradeList.vue:73-83`

`filteredTrades` se calcula correctamente, pero la paginación siempre usa `filteredTrades` como source del DataTable. En closed trades (paginados), solo se muestran los primeros 15 items filtrados pero no hay paginación visible para navegar entre páginas de resultados filtrados.

**Fix:** Agregar `rowsPerPage` y paginator dinámico que respete el filtrado.

## Mobile Bugs

### TM1 — CustomTradeList: `size="sm"` no es clase válida de PrimeVue

**File:** `src/components/ftbot/CustomTradeList.vue:69`

```html
<InputText ... size="sm" />
```

PrimeVue InputText usa `size="small"` no `"sm"`. Esto hace que el input sea del tamaño normal en mobile.

**Fix:** `size="sm"` → `size="small"`

---

### TM2 — CustomTradeList no tiene filtro funcional

**File:** `src/components/ftbot/CustomTradeList.vue:32-34, 64-70`

`filteredTrades` solo hace slice de paginación, no filtrado por texto. El InputText `filterText` está declarado pero nunca se usa para filtrar.

**Fix:** Agregar filtrado real:
```ts
const filteredTrades = computed(() => {
  const q = filterText.value.toLowerCase();
  let list = props.trades;
  if (q) {
    list = list.filter(t => t.pair.toLowerCase().includes(q) || t.enter_tag?.toLowerCase().includes(q));
  }
  return list.slice((currentPage.value - 1) * perPage, currentPage.value * perPage);
});
```

### TM4 — TradeDetail: grid de órdenes se rompe en mobile

**File:** `src/components/ftbot/TradeDetail.vue:267`

```css
grid-template-columns: minmax(6rem, 0.55fr) minmax(12rem, 1.25fr) minmax(12rem, 1fr);
```

En pantallas < 640px, las columnas de 12rem mínimo son demasiado anchas y causan overflow horizontal. El media query de línea 362 cambia a `1fr auto` que está bien, pero los `minmax` del desktop pueden causar scroll horizontal en tablets pequeñas.

**Fix:** Reducir `12rem` → `8rem` en el segundo y tercer `minmax`, o usar `minmax(0, ...)` para permitir que se encojan más.
