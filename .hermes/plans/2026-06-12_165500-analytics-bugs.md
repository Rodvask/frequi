# Analytics — Bugs y Mejoras (Desktop + Mobile)

**Goal:** Fix bugs and improve the Analytics page (`/analytics`).

---

## Bugs

### AB1 — `aggregatePerformance` trata `count: 0` como 1

**File:** `src/views/AdvancedDashboardView.vue:94`

```ts
existing.profitRatio += (row.profit_ratio ?? 0) * (row.count || 1);
```

**Problema:** Si `row.count` es `0`, el `||` lo convierte a `1`. Esto infla el profitRatio cuando hay entries con count=0. El cálculo correcto debe multiplicar por count cuando existe, y por 1 cuando es undefined/null.

**Fix:**
```ts
existing.profitRatio += (row.profit_ratio ?? 0) * (row.count ?? 1);
```

---

### AB2 — ECharts tooltip `alwaysShowContent: true` es molesto

**File:** `src/views/AdvancedDashboardView.vue:325`

```ts
alwaysShowContent: true,
```

**Problema:** El tooltip del chart de pares se muestra SIEMPRE, incluso cuando el mouse no está sobre el chart. En producción es molesto y puede cubrir otros elementos.

**Fix:** Cambiar a `false` (o eliminar la línea, el default es false).

---

### AB3 — Sin indicador de carga al refrescar

**File:** `src/views/AdvancedDashboardView.vue:422-424`

```ts
onMounted(() => {
  refreshAdvancedDashboard();
});
```

**Problema:** Cuando se monta la vista o se hace click en Refresh, no hay feedback visual. La página se ve vacía/vieja hasta que todas las llamadas API terminan.

**Fix:** Agregar un `isLoading` ref que se active durante la carga y muestre un `ProgressSpinner`.

---

### AB4 — `latestProfitRatio` no usa `profit_ratio` del registro

**File:** `src/views/AdvancedDashboardView.vue:57-59`

```ts
function latestProfitRatio(records: TimeSummaryRecord[] | undefined): number | undefined {
  return records?.at(-1)?.rel_profit;
}
```

El campo `rel_profit` puede ser `undefined` en algunos registros. No hay fallback.

**Fix:** Agregar fallback a 0 o undefined:
```ts
return records?.at(-1)?.rel_profit ?? undefined;
```
